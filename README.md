# ArsExam Desktop — Compatibility Repository

This public repository exists only to preserve update compatibility for older ArsExam Desktop installations that were released before binary/update distribution moved to a dedicated repository.

## Official downloads and updates

Current ArsExam Windows binaries, installers, update manifests and release notes are published in:

- **pgnev/arsexam-releases**

This repository does **not** contain the ArsExam application source code and is not an open-source distribution.

Older ArsExam clients may continue to contact URLs under `pgnev/arsexam-desktop`. Those compatibility endpoints redirect update metadata to the official binaries in `pgnev/arsexam-releases`.
